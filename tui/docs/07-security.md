# 07 安全与隐私

状态：设计基线  
范围：本地 TUI、Node 子进程、终端输出、日志、fixtures 和发布物

## 1. 安全目标

1. 不因使用 TUI 新增凭证泄露渠道。
2. 不允许界面输入演变成任意命令执行。
3. 不因日志内容触发终端控制序列或误导性显示。
4. 不因刷新、重试或退出产生未确认的副作用。
5. 不让真实账号数据进入源码、测试、CI 日志或发布包。
6. 后端不可用时仍能安全退出并恢复终端。

## 2. 信任边界

```text
用户输入（不完全可信）
   ↓ 白名单 Intent
Rust TUI（受信控制层）
   ↓ 固定可执行文件 + 参数数组
Node CLI（现有受信控制层）
   ↓
本地配置、凭证、反代、厂商接口

进程日志/上游错误（不可信文本）
   ↓ 控制序列清理 + 显示脱敏 + 长度限制
Ratatui 文本组件
```

- TUI 信任本机已有 `router.mjs` 的逻辑，但仍验证其输出。
- 日志、错误信息和 JSON 字符串都按不可信输入处理。
- 本机用户已经拥有一定权限；TUI 不试图成为操作系统沙箱，但必须避免扩大意外影响。

## 3. 命令注入防护

### 必须

- 使用 `tokio::process::Command` 或等价参数数组 API。
- Node 路径、脚本路径、provider ID、account key 作为独立参数。
- Action 使用封闭枚举映射到固定参数。
- provider ID 优先从后端列表映射；写操作只接受已注册且支持该动作的 ID。
- account key 来自后端账号项，不接受自由文本命令行。
- 行数、刷新间隔等数值在程序内做范围限制。

### 禁止

- `sh -c`、`cmd /c`、PowerShell 拼接用户输入。
- 在确认框提供可编辑命令。
- 把 provider title、日志文本或账号名称当作可执行路径。
- 为“支持更多操作”增加任意 Shell 页面。
- 使用模糊进程名或端口杀 TUI 自己启动的命令；进程清理由现有 router 负责。

## 4. 凭证与个人信息

### D-08 真实凭证不进入源码和发布物

禁止写入文档、fixtures、测试或发布包的内容包括：

- access token、refresh token、PAT、API Key；
- Authorization、Cookie、session、签名和解密材料；
- 真实凭证文件内容或可重放的设备授权信息；
- 真实邮箱、账号 UID、昵称组合、个人本机路径；
- 未脱敏的真实日志和提示词/响应正文。

匿名示例采用 `example-user`、`slot-a`、全零加序号 UUID、示例端口和虚构时间。不得通过“只改几个字符”处理真实秘密。

### 运行时

- TUI 不直接读取凭证文件。
- Node 后端只返回公开账号字段和状态，不返回 token。
- 登录输入由交互式 Node 子进程接收，Rust 不记录 stdin。
- 内存中的额度与账号信息只保留当前会话所需时间。
- MVP 不写入会话快照、日志数据库或云端遥测。

## 5. 日志与文本安全

### 5.1 终端转义注入

日志和子进程输出在渲染前必须：

- 去除 ANSI CSI、OSC、DCS 等控制序列；
- 去除或转义除换行/必要 tab 外的 C0/C1 控制字符；
- 不允许日志修改标题、窗口、剪贴板、cursor 或终端模式；
- 对异常超长行和 Unicode 控制字符做安全截断或可见转义；
- 不把日志片段当作 Ratatui 样式标记或终端命令执行。

直接显示原始字节不是 MVP 功能。需要完整原始日志时，提示用户使用既有文件/CLI，而不是绕过清理器。

### 5.2 显示脱敏

清理器至少覆盖：

- `Authorization: Bearer …`；
- 常见 `sk-...`、`pt-...` 等密钥形态；
- JSON 或表单中的 `access_token`、`refresh_token`、`token`、`api_key`、`session`、`cookie` 字段；
- URL query 中的 token/key/signature 参数；
- 已知的 CodeArts、Qoder、Trae、WorkBuddy 密钥格式。

脱敏是纵深防御，不替代“后端不输出秘密”。可能误伤普通文本时优先安全，并在文档中说明。不要尝试用单个万能正则解析所有 JSON；采用字段级和模式级组合，且有长度上限。

### 5.3 输出保留

- stdout/stderr、日志和错误都限制行数与字节数。
- 截断必须显示提示，不能让用户误以为看到完整输出。
- CI 测试输出不能打印完整敏感 fixture；统一使用匿名数据。
- panic 信息不包含命令环境变量、账号 JSON 或完整日志。

## 6. 副作用防护

- 启动 TUI、定时刷新、切页和 resize 不执行写命令。
- 所有 L2–L4 操作按操作文档确认，默认取消。
- `on/all/none` 显示多 provider 影响。
- 签到、真实试打、登录和账号切换不自动重试。
- 写操作全局串行，重复提交去重。
- 退出不默认强杀正在写配置的子进程。
- `--read-only` 在后端调度层阻断写操作，不能只在按钮层隐藏。
- `--demo` 在构造后端时与 NodeBackend 完全隔离，不能通过参数组合意外访问真实 root。

## 7. JSON 与数据解析安全

- 限制单次子进程 stdout/stderr 大小，防止异常进程耗尽内存。
- JSON 解析前验证顶层形状和 schemaVersion。
- 数字检查 finite、范围和单位，不直接用于分配内存或循环次数。
- 数组长度使用现有 CLI 上限和 TUI 显示上限，不根据不可信 count 预分配巨大空间。
- 时间解析失败显示未知，不 panic。
- 未知 enum 保留为未知；未知 provider 默认只读。
- 错误文本不能携带完整请求体、header 或凭证文件内容。

## 8. 文件与路径

- root 发现只检查预期 `router.mjs` 等文件，不递归扫描用户目录。
- 显式 root 必须经过存在性和预期文件检查。
- 不从后端返回的任意字符串构造要删除或覆盖的路径。
- TUI MVP 不直接写 router、账号、opencode、pi 或日志文件。
- 发布构建不包含编译机器绝对路径中的账号信息；诊断输出只显示用户主动提供的 root。

## 9. 网络安全

MVP 的 Rust 进程不直接访问厂商 API。现有 Node CLI 会访问本地端点和厂商接口，其安全策略保持不变：

- 不新增远程控制监听端口。
- 不上传使用统计、崩溃报告或账号数据。
- 不实现忽略 TLS 验证的 Rust 客户端。
- 未来远程后端必须另行设计 TLS、认证、授权、审计和撤销，不得复用本地信任假设。

## 10. OpenCode 用量数据

- 只调用官方只读 `experimental.session.stats`，不读取 OpenCode 数据库、会话标题、提示词或响应正文。
- 使用官方 `opencode.exe` 处理服务发现与认证上下文，不手工构造未认证连接，不通过 `.cmd` 拼接启动命令。
- 用量只包含会话/步骤计数、模型/provider 标识、Token、活动、工具统计和上报成本；真实会话内容不会写入 fixtures 或文档。
- OpenCode 不可用时只影响用量页，不能触发服务重启或修改配置。

## 11. 供应链与构建

- 锁定 Cargo.lock，并审查直接依赖和特性。
- Crossterm 版本与 Ratatui 匹配，避免终端状态被多个版本分割。
- CI 不下载或执行未知第三方脚本来“简化构建”。
- 发布校验 Cargo 构建和测试，再打包二进制与通用文档。
- 新依赖需要说明用途、维护状态、平台支持和许可证影响。
- 若引入新第三方运行时代码或 vendored 内容，同步检查根 `THIRD_PARTY_NOTICES.md`。

## 12. 威胁与缓解表

| 威胁 | 缓解 |
|---|---|
| account key 被拼接成 Shell 参数 | 参数数组、后端选择、动作白名单 |
| 恶意日志修改终端或剪贴板 | 控制序列清理、Ratatui 纯文本渲染 |
| 日志泄露 token | 后端最小字段、显示脱敏、输出上限 |
| 连按导致多次启动/签到 | 写任务互斥、不自动重试 |
| `on` 被误解为普通添加启用 | 高风险确认、列出其他关闭项 |
| 慢请求覆盖新状态 | request ID、generation、过期响应丢弃 |
| 退出破坏终端 | 幂等恢复、panic hook、挂起恢复测试 |
| demo 意外访问真实账号 | 后端构造隔离、不发现 root、不启动 Node |
| CI 泄露真实账号 | 匿名 fixtures、无真实凭证、禁止全量实测 |
| 错误动作成功后误判状态 | 退出码与刷新分离、未确认状态 |

## 13. 安全检查清单

每次发布前必须确认：

- [ ] 没有真实凭证、账号或日志进入 git diff。
- [ ] 所有写操作均经过统一白名单和确认/只读检查。
- [ ] 没有用户输入进入 Shell 字符串。
- [ ] 日志和任务输出经过控制序列清理与脱敏。
- [ ] 后台刷新不触发签到、登录、重启或真实试打。
- [ ] panic、错误、挂起和正常退出路径均测试终端恢复。
- [ ] 发布包不包含 `.env`、session、auth、`.run`、日志或 target。
- [ ] 安全相关测试在 Windows/Linux 均通过。

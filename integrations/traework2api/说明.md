# 1-traework2api 使用说明

Trae（TRAE SOLO）免费积分 → OpenAI 兼容 API 的本地代理。

## 目录

| 文件 | 说明 |
|---|---|
| `tw2api` | 代理二进制（**不随本仓库分发**，需从上游自行编译，见下方「获取 tw2api」） |
| `img-proxy.js` | **图片自动识别转换代理**（零依赖 Node）：请求里有图片（data:base64）→ 自动调云端千问（qwen3-vl）识别成文字 → 转发 tw2api。纯文本请求直接透传 |
| `login.sh` | 登录 Trae：打印登录链接 → 浏览器登录 → 粘贴回调链接 → 自动换 token 落盘 `auths/` + 自动签到 |
| `start.sh` | 一键启动：端口占用检查 + 依赖自检 + 启动 tw2api + 健康检查 |
| `ensure-deps.js` | DeepSeek Harness App 升级后，补装 pi-ai 缺失的 openai 依赖（自愈脚本） |
| `signin.sh` / `credit.sh` | 每日签到 / 查积分日报 |
| `config.example.json` / `.env.example` | 配置模板 |
| `启动自启示例.plist` | tw2api 的 launchd 开机自启模板 |
| `图片代理自启示例.plist` | img-proxy 的 launchd 开机自启模板 |
| `auths/` | 登录凭证目录（登录后生成 `trae-{uid}.json`，**私密，勿外传**） |

## 架构

```
OpenAI 兼容客户端（DeepSeek Harness 等）
        │
        ▼
img-proxy (127.0.0.1:7863)   ← 图片自动识别：data:image → 千问转文字
        │
        ▼
tw2api (127.0.0.1:7864)      ← Trae 免费积分通道
        │
        ▼
TRAE 云端（30+ 模型，含 DeepSeek V4 Flash/Pro、GLM 5.2）
```

## 获取 tw2api（上游源码编译，一次性）

本仓库不含 `tw2api` 二进制：上游 [Sliverkiss/traework2api](https://github.com/Sliverkiss/traework2api) 未附带开源许可证，不方便重新分发，请自行从上游构建：

```bash
git clone https://github.com/Sliverkiss/traework2api.git /tmp/tw2api-upstream
cd /tmp/tw2api-upstream
go build -o tw2api ./cmd/server    # 需 Go 1.22+
mv tw2api /PATH/TO/1-traework2api/ # 放到本目录后继续
```

## 快速开始

```bash
# 1. 登录（浏览器手机号+验证码）
./login.sh

# 2. 配置 API Key
cp .env.example .env
# 编辑 .env，TW2A_API_KEY=你的随机密钥

# 3. 启动两个服务（img-proxy 依赖 tw2api 先就绪）
./start.sh                    # 启动 tw2api (7864)
node img-proxy.js &           # 启动图片代理 (7863)（或开机自启）

# 4. 验证
curl http://127.0.0.1:7864/healthz          # → ok
curl http://127.0.0.1:7863/v1/models        # → 模型列表（带 Authorization 头）
./credit.sh                                  # → 积分日报
```

## 测试对话（纯文本 / 带图）

```bash
KEY=$(grep -o 'TW2A_API_KEY=.*' .env | cut -d= -f2)

# 纯文本
curl -X POST http://127.0.0.1:7863/v1/chat/completions \
  -H "Content-Type: application/json" -H "Authorization: Bearer $KEY" \
  -d '{"model":"DeepSeek-V4-Flash","messages":[{"role":"user","content":"你好"}]}'

# 带图片（OpenAI 格式 image_url data:base64）
curl -X POST http://127.0.0.1:7863/v1/chat/completions \
  -H "Content-Type: application/json" -H "Authorization: Bearer $KEY" \
  -d '{"model":"DeepSeek-V4-Flash","messages":[{"role":"user","content":[
    {"type":"image_url","image_url":{"url":"data:image/png;base64,<base64>"}},
    {"type":"text","text":"这张图里有什么？"}
  ]}]}'
```

## 图片自动识别说明

- **原理**：img-proxy 拦截 OpenAI 请求，发现 `image_url`（data:base64）内容块 → 调阿里云百炼 `qwen3-vl-flash` 识别成文字 → 替换为 text 块 → 转发 tw2api。模型全程只见文字，所以纯文本模型（DeepSeek V4 Flash 等）也能"看图"。
- **配置**：img-proxy 自动读取 `~/.config/see/config.env` 的 `DASHSCOPE_API_KEY` 和 `BAILIAN_MODEL`（可用环境变量覆盖）。
- **多图**：自动并发识别（限 3 并发），单图失败降级为占位符文本，不影响整轮请求。
- **零干扰**：纯文本请求直接透传，无额外延迟。

## 常见模型

`DeepSeek-V4-Flash`（省积分）· `DeepSeek-V4-Pro`（正式版）· `glm-5.2` · 豆包 Seed 系列 · Kimi · Qwen 等 30+（`/v1/models` 可查全量）

## 开机自启（macOS）

```bash
# tw2api
cp 启动自启示例.plist ~/Library/LaunchAgents/com.traework2api.plist
# 编辑 plist：把 /PATH/TO/ 改成实际路径
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.traework2api.plist

# img-proxy
cp 图片代理自启示例.plist ~/Library/LaunchAgents/com.traework2api.imgproxy.plist
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.traework2api.imgproxy.plist
```

- 登录自动启动，崩溃自动拉起（`SuccessfulExit=false` 只在异常退出时重启）
- 端口被占用时自动跳过，不抢已有实例

## 升级/换机

- 换电脑：重装 Go → `go build -o tw2api ./cmd/server`（源码：GitHub Sliverkiss/traework2api）
- 凭证迁移：把 `auths/` 拷到新机器（同一账号），无需重新登录
- 升级 Harness App 后跑一次 `./start.sh` 或 `node ensure-deps.js`（自动补 openai 依赖）

## 常见问题

| 问题 | 解决 |
|---|---|
| `invalid_api_key` | `.env` 的 `TW2A_API_KEY` 与请求的 Bearer 不一致 |
| 图片识别失败（日志 `qwen 识别失败`） | 检查 `~/.config/see/config.env` 的 DASHSCOPE_API_KEY / 网络 |
| 上游 502 | tw2api 没启动（先 `./start.sh`） |
| 积分耗尽报错 | `./credit.sh` 查看；每天 `./signin.sh` 签到 |
